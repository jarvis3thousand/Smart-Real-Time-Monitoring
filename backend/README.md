# Backend API

Node.js + Express starter API for SIH26095.

Endpoints:
- `GET /api/health`
- `GET /api/inspections`
- `GET /api/inspections/:id`
- `POST /api/inspections/:id/submit`
- `POST /api/evidence/check`

The current data store is in-memory for demonstration. Replace it with PostgreSQL/Firebase and authenticated storage for a production build.
